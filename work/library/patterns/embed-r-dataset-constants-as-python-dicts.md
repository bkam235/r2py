# embed-r-dataset-constants-as-python-dicts

## Guidance
When R code uses built-in datasets like `mtcars`, define them as module-level Python dictionaries (with column names as keys and lists as values) that can be converted to DataFrames on demand, replacing commented-out data-shim sections.
