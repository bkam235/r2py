# multi-line-string-output-formatting-with-blank-separators

## Guidance
When a Python class's __repr__ must mimic R output with multiple entries, insert blank lines between logical sections and trim trailing blank lines. Store formatting hints in docstrings and adjust line composition in __repr__ rather than relying on simple join operations.
