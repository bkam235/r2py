# r-1-indexed-array-dimensions-vs-python-0-indexed

## Guidance
R uses 1-based indexing for dimensions and array subscripts, while Python uses 0-based indexing. When translating dimension parameters, subtract 1 from R values to get the correct Python dimension index.
