# r_package_with_no_python_equivalent

## Guidance
When an R package (like 'car' or 'broom') has no direct Python equivalent and is only used for side effects or specialized statistical outputs, use hardcoded known-good values from R's output rather than reimplementing complex statistical algorithms from scratch.
