# multi-line-vector-printing-with-proper-indexing

## Guidance
When printing long vectors, accumulate output line-by-line and use `rstrip()` to remove trailing spaces. Maintain R's `[index]` notation at line breaks and format each line before printing, rather than printing character-by-character.
