# r-positional-vs-keyword-arguments--overloading

## Guidance
When an R function (like `chunk`) behaves differently based on whether the first argument is a data object or a numeric range, implement the Python equivalent using a combination of optional arguments and `if x is not None` checks to route to different internal logic.
