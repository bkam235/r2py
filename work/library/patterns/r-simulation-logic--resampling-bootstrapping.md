# r-simulation-logic--resampling-bootstrapping

## Guidance
When R code uses simulation to find p-values, implement a loop in Python that generates synthetic datasets, recalculates the statistic for each, and computes the p-value as the proportion of simulated statistics that are more extreme than the observed one.
