How the score climbs, step by step

Mean score of the best program so far after each agent step, on the same 60 training states for every line, scored with the harness as of 2026-10-18. Step 0 is the frozen starting translation. Width k keeps the best of k independent chains; 3 per step is one chain that samples 3 rewrites per step. For crashing starts the default is now width 6 with patience 5, shown measured in the "Start crashes" view; in the "All starts" view the line "default without conversation" combines it with width 3 on running starts. The black line is the current default, conversation mode included, measured on all 60 states. The shaded region shows what the three plateau strategies add after width 3 has stopped.

Model calls per step: width 1 makes 1 call, width 3 makes 3 (one per chain, in parallel), width 6 makes 6, and 3 per step makes 3. The plateau strategies make 1 call per extra step and chain they continue.

Re-scored: the programs the chains accepted were re-verified with the current harness (tag lists as rendered HTML, temp paths by extension, R session reports not scored). This changed 10 of the 60 states; the starting mean rose from 0.405 to 0.427. The chains' choices were made under the old scoring, so their paths are not what a fresh run would take.

Where the lines come from: the 240 replay runs of 2026-10-17. Each width-3 run holds three independent chains, giving 6 single chains per state; width 1 and 3 average the best over every 1- and 3-chain subset of those 6. In the "All starts" and "Start runs" views, the dotted width-6 line is the best of all 6 single chains per state: an estimate, not a run.

New default for crashing starts (since 2026-10-18): 6 chains, 5 failed steps in a row before a chain stops while its program still crashes, and twice the time limit. Its line in the "Start crashes" view is measured, one run per state on 2026-10-19 with the 40-minute limit (only 1 of 120 chains reached it): it ends at 0.676, against width 3 at 0.611. Against the two width-3 runs of 2026-10-17 it gains +0.052 (95% interval -0.021 to +0.126; better on 9 states, worse on 3, tied on 7), so the gain is likely but not established at this size, and the runs were two days apart. The first measured run with the 20-minute limit ended at 0.646. The "default without conversation" line in the "All starts" view is the step-by-step mean of width 3 on the 41 running starts and this measured line on the 19 crashing starts.

Default with conversation (measured): the production default as of 2026-10-20, run on all 60 states on 2026-10-20 (one run per state): width 3 on running starts; width 6, patience 5 and twice the time limit on crashing starts; from step 2 on, each step continues the previous step's conversation and is told what its answer did. It ends at 0.782 on all starts (0.765 running, 0.819 crashing). Against width 3 on running starts it gains +0.045 (95% interval +0.008 to +0.092; better on 16 states, worse on 9). On crashing starts the +0.143 over the crash default without conversation comes mostly from three states that crashed in that run and run in this one; with one run per state such swings are largely chance. The comparisons are with runs one to three days earlier.

Plateau strategies (run on 2026-10-18 with the current harness, each continuing from where the width-3 runs stopped): restart continues the program a run returned for 3 steps with a fresh history; accept equal does the same and also takes a different program with the same score; patience 5 gives the 44 chains that stalled while their program still crashed 2 more steps. Each extension is drawn as the gain measured on the two width-3 runs per state, added to the end of the width-3 line. Restart and accept equal only apply to running starts; patience only to crashing programs.
