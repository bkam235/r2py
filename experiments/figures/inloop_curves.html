How the score climbs, step by step

Mean score of the best program so far after each agent step, on the same 60 training states for every line, the starting programs and the DeepSeek default re-scored with the scorer of epoch 17 (2026-11-21); the other lines frozen at epoch 14 (2026-11-16). Step 0 is the frozen starting translation. Width k keeps the best of k independent chains; 3 per step is one chain that samples 3 rewrites per step. For crashing starts the default is now width 6 with patience 5, shown measured in the "Start crashes" view; in the "All starts" view the line "default without conversation" combines it with width 3 on running starts. The black line is the current default, conversation mode included, measured on all 60 states. The shaded region shows what the three plateau strategies add after width 3 has stopped.

Model calls per step: width 1 makes 1 call, width 3 makes 3 (one per chain, in parallel), width 6 makes 6, and 3 per step makes 3. The plateau strategies make 1 call per extra step and chain they continue.

Re-scored: every program the curves use (the starting programs and every program a chain accepted) is re-verified with a scorer, without model calls: the starting programs and every program of the DeepSeek default with the scorer of epoch 17 (2026-11-21); the other lines keep their scores from epoch 14 (2026-11-16), when they were last re-scored (from 2026-11-16 a new epoch re-scores only the production default's line). The fixes of 2026-10-17/18 (tag lists as rendered HTML, temp paths by extension, R session reports not scored) raised the starting mean from 0.405 to 0.427; the checkpoint fix of 2026-10-25 to 0.473, because 5 start states had crashed only because of the harness; under epoch 4 (2026-10-26) it is 0.485, because one more state (ragg agg_webp_anim) had been stored as crashing by mistake. A state's stratum is its re-scored start: 46 running, 14 crashing. The chains' choices were made under the old scoring, so their paths are not what a fresh run would take.

Where the lines come from: the 240 replay runs of 2026-10-17. Each width-3 run holds three independent chains, giving 6 single chains per state; width 1 and 3 average the best over every 1- and 3-chain subset of those 6. In the "All starts" and "Start runs" views, the dotted width-6 line is the best of all 6 single chains per state: an estimate, not a run.

New default for crashing starts (since 2026-10-18): 6 chains, 5 failed steps in a row before a chain stops while its program still crashes, and twice the time limit. Its line in the "Start crashes" view is measured, one run per state on 2026-10-19 with the 40-minute limit (only 1 of 120 chains reached it): re-scored, it ends at 0.795 on the 14 crashing starts, against width 3 at 0.756. Before the checkpoint fix (19 crashing starts, 5 of them crashing only because of the harness) it gained +0.052 over the two width-3 runs of 2026-10-17 (95% interval -0.021 to +0.126), likely but not established at this size, and the runs were two days apart. The first measured run with the 20-minute limit ended at 0.646. The "default without conversation" line in the "All starts" view is the step-by-step mean of width 3 on the 46 running starts and this measured line on the 14 crashing starts.

Default with conversation (measured): the production default as of 2026-10-20, run on all 60 states on 2026-10-20 (one run per state): width 3 on running starts; width 6, patience 5 and twice the time limit on crashing starts; from step 2 on, each step continues the previous step's conversation and is told what its answer did. Re-scored, it ends at 0.791 on all starts (0.773 running, 0.850 crashing), against 0.741 for the default without conversation. Measured before the re-scoring, it gained +0.045 over width 3 on running starts (95% interval +0.008 to +0.092; better on 16 states, worse on 9). On crashing starts its gain came mostly from three states that crashed in one run and ran in the other, partly states that crashed only because of the harness; with one run per state such swings are largely chance. The comparisons are with runs one to three days earlier.

Later defaults (measured): default 2026-11-01 adds entity-addressed feedback (each losing entity is shown the comparison that scores it), replayed once on all 60 states on 2026-11-05. Default 2026-11-12 runs the agent on DeepSeek V4.1 Flash (seeds, the review and the mapping stay on Gemma), lets it probe the script's own R state without a stall, and rejects candidates that paste R's values (the LLM review and literal_check, crashing candidates included); run once on all 60 states on 2026-11-12. Re-verified under epoch 9 its final programs score 0.881 against 0.816 for the 2026-11-01 default (paired +0.065, 95% interval +0.026 to +0.099), and 0.904 against 0.816 on the 46 held-out states (+0.088). The curves count steps, not calls: a DeepSeek step costs about as much as a Gemma step but probes the R state about five times per run.

The 11-12 default replayed (2026-11-16, under epoch 16, after the scoring corrections of epochs 10-16, which also changed the feedback the agent sees): its final programs score 0.909 on the 60 training states against 0.866 for its first run re-scored under the same epoch (paired +0.043, 95% interval +0.010 to +0.082). The gain sits in the 9 states whose measurement faults those epochs fixed (+0.252 per state, +0.038 of the +0.043; read after the fact); on the other 51 states it is +0.006 (-0.011 to +0.024). On the 46 held-out states the replay scores 0.902 against 0.907 (-0.005, -0.021 to +0.010), and its share of finals >= 0.95 falls from 0.652 to 0.565: the corrections let the agent finish states it was mismeasured on, and changed nothing else measurable. One run per state each time; a replay moves by about 0.03 on its own.

Default 2026-11-21, the current default, is the 11-12 default with the stop threshold raised from 0.9 to 0.95: a chain whose best program reaches 0.9 keeps working until 0.95. A test on both pools found that continuing such chains at 0.95 beats spending the same calls on more chains at 0.9. Run once on all 60 states on 2026-11-21 (epoch 17): its final programs score 0.921 against 0.910 for the 11-16 replay re-verified under the same epoch (paired +0.011, 95% interval -0.005 to +0.030), and its share of finals >= 0.95 rises from 0.583 to 0.717. On the 46 held-out states: 0.915 against 0.902 (+0.013, -0.002 to +0.030), share 0.565 to 0.696. It costs 16-19% more calls per run. One run per state, so the plateau gain is within a replay's own noise; the share gain is about at its limit.

Plateau strategies (run on 2026-10-18 with the current harness, each continuing from where the width-3 runs stopped): restart continues the program a run returned for 3 steps with a fresh history; accept equal does the same and also takes a different program with the same score; patience 5 gives the 44 chains that stalled while their program still crashed 2 more steps. Each extension is drawn as the gain measured on the two width-3 runs per state, added to the end of the width-3 line. Restart and accept equal only apply to running starts; patience only to crashing programs.
